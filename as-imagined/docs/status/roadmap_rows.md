Injecting the plausible misreading is not a formality after the tests pass — it is the only thing separating a guard from a decoration; when the first injection passes, suspect the assertion before crediting the code. **THE PREVENTIVE FORM, which is what actually works: derive each assertion from the NEGATION, not from the truth.** The habit that produces weak guards is writing "what does the correct version do?" and asserting that. (13) **A fixture where two competing rules AGREE cannot tell them apart.** Batch 31's Helping Hand guard used a stage where the partner rule and the side rule both give the same answer, so deleting the partner rule passed; batch 32's Dragon Rush guard asserted only that two sides DIFFER, which is true whichever battler you key on, because attacker and target are always opposite in singles.
