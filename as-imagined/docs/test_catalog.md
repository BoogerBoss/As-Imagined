- `scenes/battle/m36_leak_harness.tscn` — **[M36]** whole-roster LEAK / clean-run harness (784 tests): runs all 778 playable in-scope move scripts end to end and checks each TERMINATES, does not end in VM ERROR, leaves every battler at its resting position/scale/rotation/visibility/modulate/material, leaves no sprite or clone on the layer, and clears the scanline band. **This is defect detection, NOT fidelity verification** — it cannot tell you an animation looks right, only that it ran and cleaned up after itself. Its first run found **23 real leaks across 22 moves** (**all since FIXED at the root, 2026-08-03 — the baseline is EMPTY and must stay so**), one root cause in three dresses (the VM's cleanup nets only cover the TRACKED path, so direct `node.rotation`/`node.modulate`/`node.scale` writes and sprites never passed to `notify_spawned` all escape). Those are PINNED in `KNOWN_LEAKS` as a baseline that fails if the set changes in either direction; **shrinking it is the definition of done**, and the fix is a core-VM change deliberately left as its own task.
